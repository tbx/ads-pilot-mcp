    Dry run by defaultProbelauf ist Standard

    Allowlist per accountFreigabeliste pro Konto

    Write access only to the accounts listed in the profile. Claude cannot change that list. Reading works everywhere.Schreibzugriff nur auf die Konten im Profil. Claude kann diese Liste nicht ändern. Lesen geht überall.

    Always clear whereImmer klar, wo

    One profile per client, chosen at startup. Every answer names profile and account ID.Ein Profil pro Kunde, beim Start festgelegt. Jede Antwort nennt Profil und Konto-ID.

    No deletingKein Löschen

    Pause and enable, nothing else. Everything can be undone.Pausieren und aktivieren, sonst nichts. Alles lässt sich zurücknehmen.

No developer token needed. The setup guide walks you through the Google Cloud Console click by click. Kein Developer Token nötig. Die Anleitung führt Klick für Klick durch die Google Cloud Console. 

# install
git clone https://github.com/tbx/ads-pilot-mcp.git
cd ads-pilot-mcp && uv sync

# one profile per client, sign in once
cp profiles/example.yaml profiles/fjord.yaml
uv run ads-pilot-login fjord

# test, changes nothing
ADS_PILOT_PROFILE=fjord uv run ads-pilot-check

Roadmap

ads-pilot grows in four versions. Version 1 is available today, the others are planned. Dry run, allowlist and change log apply to every version. ads-pilot wächst in vier Versionen. Version 1 ist heute verfügbar, die weiteren sind geplant. Probelauf, Freigabeliste und Protokoll gelten für jede Version.
